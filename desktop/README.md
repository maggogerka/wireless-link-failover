# Desktop application

Здесь находится первая версия `Wireless Link Failover Console` — программа на
Python 3.11 со встроенным интерфейсом Tkinter.

Программа умеет:

1. обнаруживать доступные последовательные порты;
2. распознавать узлы по сообщению `device_info`;
3. запускать статистические серии ESP-NOW и задавать ACK delay;
4. безопасно передавать Wi-Fi-пароль без записи в журнал;
5. запускать статистические серии UDP через точку доступа;
6. настраивать и наблюдать автомат ESP-NOW → UDP → ESP-NOW;
7. сохранять входящие JSON Lines без изменения исходных данных.

В блоке `Контролируемое ухудшение ESP-NOW` можно отключить ответы ESP-NOW ACK
ровно на одной выбранной плате. Это создаёт воспроизводимую потерю подтверждений
для проверки автоматического перехода, не отключая Wi-Fi и UDP. Перед новым
повтором сначала выбирается отправитель и нажимается
`Подготовить выбранного отправителя`. Автомат запускается только на нём, а
вторая плата остаётся пассивным приёмником; это исключает синхронные встречные
probe из измерения. Затем выбирается приёмник и на нём отключается ACK.

## Запуск

```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -e .
.venv\Scripts\python -m wlf_console
```

После первой установки программу также можно запускать двойным щелчком по
`run_console.cmd`.

SSID и пароль вводятся в блоке `Wi-Fi / UDP`. В журнале команда отображается
как `WIFICONFIG <redacted>`, а поле пароля очищается сразу после отправки.
